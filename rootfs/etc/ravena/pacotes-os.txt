# RAVENA OS -- OS-1: manifesto declarativo de pacotes da camada OS
#
# O que e: lista FECHADA e verificada do que entra (ou nao entra) na camada OS
# do Ravena OS. Nada disto esta instalado pelo build (`build_rv10v20.sh` so faz
# mksquashfs+xorriso) -- o rootfs e preparado antes. Este arquivo e a FONTE
# DECLARATIVA para poder reconstruir um host do zero e para nao deixar
# ferramenta virar "paquete solto" sem origem.
#
# FORMATO -- 5 campos, separados por " | ", sem espaco antes/depois:
#   pacote | repo | categoria | origem | nota
#
# repo (enumerado, o teste valida):
#   extra       = repo oficial Arch (extra/core)  -- verificado em 2026-10-09
#   aur         = AUR                              -- verificado em 2026-10-09
#   nao_pacote  = aparece no catalogo mas NAO e pacote instalavel
#                 (lista, lab, dados, distro, VM)
#   rejeitado   = candidato do catalogo que NAO entra, com motivo= na nota
#
# origem (enumerado, o teste valida):
#   doc1#<n>    = indice n do manifesto de repos do 1o .docx
#   doc2#<n>    = indice n do manifesto de repos do 2o .docx
#   plano-OS-1  = piso basico de host Linux, decidido no plano e NAO consta
#                 dos .docx (usado so para clamav/fail2ban/lynis)
#
# categoria (enumerado, o teste valida):
#   integridade | rede | deteccao | forense | antivirus | auditoria |
#   pentest | osint | scanner | conteudo | runtime
#
# COMO INSTALAR (manual, nunca automatico no build):
#   extra : sudo pacman -S --needed <pacote>
#   aur   : yay -S --needed <pacote>          (exige yay; AUR = build manual)
#
# VERIFICACAO DA ORIGEM DOS DADOS:
#   extra : https://archlinux.org/packages/search/json/?name=<pacote>
#   aur   : https://aur.archlinux.org/rpc/v5/info?arg[]=<pacote>
#   Ambos consultados em 2026-10-09. Pacote marcado "extra" ou "aur" SEM ter
#   sido achado nessas duas fontes = bug de manifesto.
